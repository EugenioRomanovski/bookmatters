# Bookmatters

Русскоязычные клубы медленного чтения. React 19 + Vite, Supabase Auth/Postgres, публикация в Vercel.

## Продуктовый сценарий

1. Читатель видит открытый каталог. Пример клуба явно отмечен как демонстрационный и не создаёт фиктивных записей.
2. Вход или регистрация через email и одноразовый код. Используется общий Supabase-проект Encore (`uvuifuyozscfcowuxdtr`) и существующий API-прокси `api.brainsome.app`. У пользователя тот же аккаунт, что в Encore/Winenote; сессия этого сайта хранится отдельно.
3. Организатор задаёт клуб, книгу, страницы, дату старта, число недель, время встреч в UTC и необязательную HTTPS-ссылку.
4. Одна транзакция создаёт клуб, членство организатора и недельные этапы с полным непересекающимся диапазоном страниц.
5. По ссылке `/?club=<uuid>` участник открывает клуб и вступает. Клубы открытые; выбранные имена участников публичны, email не публикуются.
6. Обсуждения по этапам: мысли, вопросы и цитаты. Будущие этапы закрыты до даты начала, включая прямой REST-доступ. Встречу можно экспортировать в ICS.
7. Личные заметки и текущая страница доступны только автору. Читатель может выйти из клуба; организатор остаётся владельцем.

## Архитектура

Статический SPA без собственного API-сервера. Браузер обращается к Supabase с publishable key. Авторизацию обеспечивает Supabase Auth; права на данные проверяет Postgres RLS, а не клиент.

Таблицы `public.bm_clubs`, `bm_members`, `bm_stages`, `bm_posts`, `bm_progress` изолированы от существующих приложений префиксом. Связи с пользователями идут на существующую `auth.users`. Общие `profiles`, дружбы и таблицы Encore/Winenote не менялись.

RPC `bm_create_reading_club` работает с SECURITY INVOKER. Все операции внутри неё выполняются с правами пользователя и RLS. Старый промежуточный RPC `bm_create_club` закрыт для клиентов в удалённой базе.

Приватные таблицы закрыты для `anon`. Сообщения доступны только участнику клуба после открытия этапа; редактирование и удаление чужих сообщений запрещены. Имена — пользовательский публичный текст, не основание для авторизации. Все права проверяются по `auth.uid()`.

## Запуск

```sh
npm ci
npm run dev
npm run build
```

Клиентский publishable key публичный по определению; service role и серверные секреты не используются. Версии зависимостей зафиксированы в `package.json` и lockfile.

## Проверки

- Production-сборка прошла с установленными через `npm ci` версиями.
- `database/verification.sql`: транзакционный интеграционный тест реальной базы с откатом. Проверены создание клуба, деление страниц, время встреч, вступление, изоляция заметок, закрытие будущих обсуждений и запрет анонимного доступа. Тестовые пользователи и данные не сохраняются.
- Проверен публичный API: каталог возвращает HTTP 200, сообщения без входа возвращают HTTP 401; email Auth включён, регистрация разрешена.
- Supabase security advisors: новых предупреждений по Bookmatters нет. Существующие предупреждения других приложений не менялись.
- Браузерная проверка и реальная доставка OTP не выполнены: в рабочем окружении нет инструмента браузера; отправка писем пользователям не проводилась.

## Публикация

Vercel: Vite, build `npm run build`, output `dist`. `vercel.json` содержит SPA rewrite и базовые HTTP-заголовки. Целевая команда `brainsome`, домен `bookmatters.brainsome.app`.

Исходники: https://github.com/EugenioRomanovski/bookmatters.

Приложение опубликовано: https://bookmatters.vercel.app. GitHub подтверждает успешное production-развёртывание коммита `788e0a3`. HTTP-проверки страницы, JS и CSS возвращают 200; запрос каталога Supabase с Origin опубликованного сайта проходит и получает корректный CORS.

Рабочий домен: https://bookmatters.brainsome.app. Подключение Vercel не показывает существующий проект в списке и возвращает Project not found при запросах проекта; публикация проверяется через статусы GitHub и HTTP. Добавить `bookmatters.brainsome.app` можно через https://vercel.com/brainsome/bookmatters/settings/domains. DNS-зона brainsome.app уже управляется Vercel и имеет wildcard. Требуемые DNS-изменения, если Vercel их запросит, следует брать из настроек домена; почтовые и API-записи не менять.

Браузерная проверка и фактическая доставка OTP остаются непроверенными. Runtime logs через подключение Vercel недоступны.

## Текущие границы первой версии

Одна книга на клуб, недельные этапы по главам (по умолчанию) или страницам, открытые и закрытые клубы, обсуждения по этапам. Друзья и профили общие с Encore/Winenote; приглашения принимаются внутри приложения. Организатор может менять видимость клуба. Нет встроенного текста книги, платежей, автоматических email-напоминаний и видеозвонков. Для созвона используется ссылка организатора. Новые сообщения загружаются при входе в этап, после отправки и кнопкой «Обновить».

## Установка на домашний экран (PWA)

- Android: откройте сайт в Chrome → меню → «Установить приложение» / «Добавить на главный экран».
- iPhone/iPad: откройте сайт в Safari → «Поделиться» → «На экран Домой». Если доступен переключатель «Открывать как веб-приложение», оставьте включённым.

Манифест `/manifest.webmanifest` задаёт постоянный идентификатор, имя Bookmatters, область `/`, самостоятельное окно и цвета запуска. Подготовлены PNG 192/512, отдельная maskable-иконка Android с безопасными полями, Apple Touch Icon 180/167/152 и favicon. Системные скругления накладывает устройство.

После сборки `scripts/build-sw.mjs` создаёт версионированный service worker из файлов `dist`. Кешируется только публичная оболочка: HTML, стили, скрипты и иконки. При отсутствии сети можно открыть оболочку; для загрузки клубов, входа и сохранения данных нужно соединение. Supabase-запросы и личные записи service worker не кеширует. Новая версия активируется после закрытия старых вкладок, без принудительной перезагрузки несохранённого текста.

Если старая иконка уже сохранена на домашний экран, для надёжного обновления удалите старый ярлык и установите приложение заново.

## Подготовленное мобильное обновление

Новый интерфейс, открытые/закрытые клубы, общие друзья и приглашения, чтение по главам или страницам описаны в [плане выпуска](docs/mobile-clubs-release.md). Миграция production одобрена пользователем, применена и проверена регрессионным тестом с откатом. Новых предупреждений безопасности Bookmatters нет.

Локальная проверка без доступа к production:

```sh
npm ci
npm run test:db
npm run build
```
